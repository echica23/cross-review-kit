# 記録項目仕様（サンプル）

この文書はクロスレビューの動作確認用フィクスチャです。特定の業務手順を表しません。

## 要求

| ID | 内容 |
| --- | --- |
| R1 | `id` は必須。1以上の整数であり、既存の記録と重複できない。 |
| R2 | `name` は必須。1文字以上20文字以下。先頭と末尾の空白は許さない。 |
| R3 | `status` は必須。`draft` または `active` のいずれか。初期値は `draft`。 |
| R4 | `note` は任意。最大100文字。 |
| R5 | `status` を `active` にできるのは、`id` と `name` がこの仕様を満たす場合だけである。 |
| R6 | `id` は作成後に変更できない。 |
